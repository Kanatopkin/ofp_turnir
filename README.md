# Турнир по подтягиванию на перекладине памяти героев СВО
Веб-приложение на Streamlit с покадровым ИИ-судейством (MediaPipe Pose + State Machine) и синхронизацией с Google Drive.

## Деплой в Streamlit Cloud
1. Загрузите файлы проекта в репозиторий `https://github.com/Kanatopkin/ofp_turnir`.
2. Подключите репозиторий на `share.streamlit.io` (главный файл: `app.py`).
3. Добавьте ключи из `.streamlit/secrets.toml.example` в раздел `Advanced settings -> Secrets`.
